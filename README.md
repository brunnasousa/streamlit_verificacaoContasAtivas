# Inteceleri Dashboard

- Esta aplicação foi desenvolvida para facilitar a administração de contas e e-mails institucionais, além de verificar a atividade de usuários e gerar scripts para instalação e desinstalação de aplicativos.


## 💻 Funcionalidades::

1. **Dados Resumidos do Admin:**
Apresenta um resumo das principais informações de administração do sistema.
Inclui dados como o número de contas ativas, informações sobre e-mails e detalhes administrativos relevantes.

2. **Verificação de Contas Ativas:**
Permite fazer upload de uma lista de e-mails e verificar quais contas foram ativadas ou permanecem desativadas.
Útil para controle de acesso e gestão de usuários.

3. **Criação de E-mails Institucionais:**
Gera e-mails institucionais para usuários em massa.
Elimina duplicações e facilita o processo de criação de contas institucionais no Google Workspace.

4. **Script BAT para Instalar e Desinstalar:** Apps
Gera scripts .BAT personalizados para instalação e desinstalação de aplicativos, com parâmetros ajustáveis para diferentes necessidades de implementação.
Oferece instruções de uso para a ferramenta de geração de scripts.

## 👀 Como Usar
1. Ao abrir, selecione a opção desejada no menu lateral esquerdo:

- Dados Resumidos do Admin
- Verificação de Contas Ativas
- Criação de E-mails Institucionais
- Script BAT para Instalar e Desinstalar Apps

2. Requisitos
- Python 3.x
- Streamlit
- Bibliotecas adicionais podem ser encontradas no arquivo requirements.txt

## 🎯 Instalação


1. Clone o repositório:
   ```bash
   git clone git@github.com:desenvolvimento-inteceleri/streamlit-dashboard.git

2. Instale as dependências:
   ```bash
    pip install -r requirements.txt

3. Execute a aplicação:
   ```bash
    streamlit run app.py

## 💾 Tecnologias Utilizadas
- Python 3: Linguagem principal da aplicação.
- Streamlit: Framework utilizado para criar a interface web interativa.
